# collage
A .net api and angular app that stores, retrieves and displays photos using AWS S3 and DynamoDB. I built this to replace our wedding website and show off photos from the wedding since we already have the domain.
To run locally you will need to set up localstack for yourself: https://docs.localstack.cloud/aws/getting-started/installation/
video/s you want to display through knockout text need to be placed in ./collage/collageApp/public
